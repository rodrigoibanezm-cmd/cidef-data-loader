# Semántica analítica CIDEF

Input conceptual:

```text
evidence_bundle.v1
→ concepto de negocio

```

El documento no enruta ejecución.

## Escala de conclusión
```text
hecho observado
→ señal
→ brecha / ventaja / deterioro
→ oportunidad / riesgo / fortaleza
→ red flag / prioridad
```

Categorías más fuertes requieren más evidencia compatible, no menos.

- Brecha: resultado + referencia válida + diferencia cuantificable.
- Deterioro: evolución adversa + referencia + soporte temporal/comparativo.
- Oportunidad: resultado + referencia + brecha + disponibilidad/capturabilidad compatible.
- Ventaja: desempeño favorable + referencia + diferencial positivo.
- Fortaleza: ventaja + persistencia/repetición.
- Riesgo: señal adversa + referencia + soporte compatible con deterioro futuro posible.
- Red flag: sólo con criterio determinista explícito de materialidad/excepcionalidad.
- Prioridad: hallazgo sustentado + relevancia + accionabilidad + base válida para competir por atención.

`COMPLETE/PARTIAL/INSUFFICIENT` proviene del `evidence_bundle` y es relativo a la pregunta.
