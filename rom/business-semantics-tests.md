# Pruebas conceptuales de semántica

Estas pruebas validan:
```text
intent.v1
→ analysis_iteration.v1 completadas hasta STOP
→ conclusión máxima permitida
```

No validan elección de capability por el agente.

1. Oportunidad: sin evidencia compatible de disponibilidad/capturabilidad, una brecha queda como señal/brecha, no oportunidad.
2. Fortaleza: un único período favorable no basta.
3. Acción: si sólo existen M focos sustentados, no completar N>M con tareas inventadas.
4. Evidencia PARTIAL: sintetizar sólo dimensiones disponibles; no reconstruir las faltantes.
5. Conflicto/limitación: nunca escoger silenciosamente una fuente para producir una conclusión más fuerte.
